# Security policy

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/ahmed-abdat/nezzel-desktop/security/advisories/new) (**Security → Advisories → Report a vulnerability**), or email [contact@hululsoft.mr](mailto:contact@hululsoft.mr). Don't open a public issue with vulnerability details.

Include the Nezzel version, your OS, the impact and short steps to reproduce, using public test links or made-up inputs. Never send passwords, cookies, cookies.txt files, access tokens, private links or unredacted logs. Describe their shape instead.

Most useful: command or argument injection into yt-dlp, ffmpeg or other tools, path traversal or writing outside the chosen folder, cookies or saved logins leaking, and anything that weakens update or tool-download checks (signatures, SHA-256 hashes).

Test only on your own computer and accounts. We'll work on a fix and agree on disclosure with you through the private report. There is no promised response time and no bounty.

## Supported versions

Nezzel Desktop is in beta. Fixes go into the [latest release](https://github.com/ahmed-abdat/nezzel-desktop/releases/latest) and the main branch; older versions get no backports. Download failures, site problems and feature ideas belong in the [public issues](https://github.com/ahmed-abdat/nezzel-desktop/issues/new/choose).
